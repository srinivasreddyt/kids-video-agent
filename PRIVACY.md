# Privacy Policy

Kids Video Agent is a personal automation tool that generates videos and uploads them to the
owner's own YouTube channel using the YouTube Data API.

- It accesses only the owner's own Google account, solely to upload videos and thumbnails.
- It does not collect, store, sell, or share personal data from any other user.
- OAuth credentials are stored as encrypted GitHub Actions secrets and are used only for uploads.
